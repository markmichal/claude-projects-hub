# files

Things people can download or open straight from the site: PDFs, decks,
anything that is not a web page.

Linked from `projects.js` with a path like `files/name.pdf`, which the browser
reads as an address on this site.

Why these live here rather than being linked somewhere else: a file in this
folder is published with the site, needs no login, and keeps working even if
whatever it came from is gone or restricted later.
